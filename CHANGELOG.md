## 0.1.1 (September 17, 2019)
  (0.1.1 V) is the first version of the application launched on the production environment
  This version contains the following main features:
  - Create an auction.
  - Create a DsItem (Direct Sell Item). 
  - signup/sign in  by mobile number.
  - Add user profile.
  - Edit user profile.
  - Become Seller Request.
  - auto-generate chat after an "Auction" ended between the seller and a buyer(winner).
  - a buyer can communicate with the seller who owns the "DsItem" by creating a private chat between him and the seller for the agreement
